# Tripnic: Landing Page

A responsive landing page for a fictional travel agency, "Tripnic Travels", built with HTML, CSS and a little JavaScript.

## Sections

Welcome hero, About Us, Our Tours and Destinations.

## Run it

No build step. Open `index.html` in a browser.

## Files

- `index.html`: markup
- `style.css`: styles
- `script.js`: interactions
